## 修改内容

### 录入界面（ImportScreen）

**题型标签**：单选题 / 多选题 / 主观题（横向 Chip 切换）

**选项录入（风格1 — 标签式）**：
- 每个选项行：字母标签(A/B/C/D) + 文本输入框 + 正确标记按钮(✓) + 删除按钮(×)
- 单选题：仅可标记 1 个正确项
- 多选题：可标记多个正确项
- 点击"添加选项"新增空选项行
- 选项内容可为空，保存后默认显示字母(A/B/C/D)
- 主观题：不显示选项区域

**保存**：
- 选项以 `|` 分隔存储（如 "长投|交易性金融资产||"）
- 正确答案以字母存储（单选 "A"，多选 "AB"）

### 复习界面（ReviewScreen）

**选择题**：
- 单列布局，上方题目区 + 下方选项按钮
- 单选：圆形 radio，单选模式
- 多选：方形 checkbox，多选后提交
- 提交后对比答案：
  - 正确选项绿色高亮
  - 用户选错项红色高亮
  - 底部结果横幅（✅正确 / ❌错误）
  - "下一题"按钮

**主观题**：
- 显示题目内容
- 提示"主观题不评判，需自行对比后自评"
- 三个按钮：答对了 / 答错了 / 跳过

### 数据库（不变）

Mistake 表结构不变：
- `options` 字段存储选项（`|` 分隔）
- `correctAnswer` 字段存储正确答案字母
- `referenceAnswer` 保留但本期不录入
- `questionType` 枚举：SINGLE_CHOICE / MULTI_CHOICE / ESSAY
