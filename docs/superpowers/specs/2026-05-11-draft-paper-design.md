# 复习草稿纸功能设计

> 日期：2026-05-11

## 一、整体布局

**答题页面采用左/右分栏：**
- **右侧**：题目显示区（显示 OCR 识别的题目文字）
- **左侧**：作答/草稿纸切换区

**顶部工具栏**横跨整个屏幕，上方显示，下方是题目和草稿纸区域。

---

## 二、顶部工具栏布局

**左侧 80%**：
```
[撤销 | 重做] | [笔 | 橡皮擦 | 纸张 | 清空] | [150%]
```

**右侧 20%**：根据选中工具显示细分选项面板

---

## 三、工具栏功能详情

### 1. 笔工具

**点击笔 → 右侧显示颜色选择 + 粗细选择**

**颜色区域：**
- 三个默认颜色按钮横排：蓝、黑、红
- 长按任意一个默认颜色 → 展开自定义面板
  - 上排：6 个自定义颜色槽位（初始为空，点击弹出调色盘添加）
  - 下排：网格形调色盘区域
  - 点击自定义颜色可替换该槽位
  - 直接在调色盘区域选择颜色可替换当前默认颜色

**粗细区域：**
- 三个粗细按钮横排：0.1mm、0.3mm、0.5mm
- 点击任意一个按钮 → 弹出滑块调节（范围：0.1mm - 3mm），调节后可替换该按钮的值

### 2. 橡皮擦工具

**点击橡皮擦 → 右侧显示大小滑块**
- 滑块范围：5px - 50px（像素级）
- 画布上显示圆圈光标预览擦除范围

### 3. 纸张工具

**点击纸张 → 右侧显示：**
- 背景选择：空白 / 网格（40dp间隔）/ 横线（60dp间隔）
- 底色选择：黑色（#242424）/ 白色（#FFFFFF）/ 肉色（#F5E6D3）

### 4. 撤销/重做

- 撤销：回退一步
- 重做：恢复一步

### 5. 清空

- 一键清除所有内容
- 弹出确认对话框

### 6. 缩放比例显示

- 显示当前缩放比例，格式如 "150%"
- 范围：100% - 500%

## 四、交互逻辑

### 笔写模式（只用触控笔）

- 触控笔落下（ACTION_DOWN）→ 自动锁定缩放/移动
- 触控笔抬起（ACTION_UP/CANCEL）→ 自动解锁，恢复缩放/移动
- 手指不可书写，只用于缩放/移动（笔抬起时）

### 草稿纸切换

- 作答区和草稿纸通过按钮切换
- 切换后内容保留（草稿纸笔记不丢失）

### 提交后

- 草稿纸自动清除
- 进入下一题

## 五、技术实现

- 草稿纸使用 `HandwritingView` 组件（需重新设计）
- 复习页面左右分栏布局
- 工具栏通过 Compose 实现，工具状态由 ViewModel 管理
- 手写数据通过 Path 矢量绘制，支持撤销/重做
